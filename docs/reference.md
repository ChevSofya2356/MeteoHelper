# Справочная информация

Параметры, разрешения и технические характеристики MeteoHelper.

---

## Параметры формулы Risk

Индекс риска рассчитывается по формуле:

Risk = (ΔP / 8) × W1 + (ΔT / 10) × W2 + (Kp / 5) × W3 + (ΔH / 20) × W4

Весовые коэффициенты приведены в таблице 2.

**Таблица 2 — Параметры формулы Risk**

| Параметр | Значение | Описание |
|----------|----------|----------|
| `W1` | 0.3 | Вес атмосферного давления |
| `W2` | 0.2 | Вес температуры |
| `W3` | 0.3 | Вес Кр-индекса |
| `W4` | 0.2 | Вес влажности |
| `ΔP` | мм рт. ст. | Дельта давления за сутки |
| `ΔT` | °C | Дельта температуры за сутки |
| `Kp` | 0–9 | Планетарный Кр-индекс |
| `ΔH` | % | Дельта влажности |

## Разрешения Android

Перечень разрешений, используемых приложением, приведён в таблице 3.

**Таблица 3 — Разрешения Android**

| Разрешение | Назначение | Обязательное |
|------------|------------|--------------|
| `POST_NOTIFICATIONS` | Push-уведомления в 07:55 | Да |
| `SCHEDULE_EXACT_ALARM` | Точное срабатывание будильника (Android 12+) | Да |
| `ACCESS_BACKGROUND_LOCATION` | Автоопределение региона | Нет |
| `INTERNET` | Загрузка метеоданных | Да |

## Внешние API

Приложение использует два внешних API:

- **Open-Meteo** — `https://api.open-meteo.com/v1/` (метеоданные);
- **NOAA SWPC** — `https://services.swpc.noaa.gov/` (Кр-индекс).

---

## Пример запроса к API


curl "https://api.open-meteo.com/v1/forecast?latitude=55.75&longitude=37.62&hourly=temperature_2m,surface_pressure,relative_humidity_2m"
