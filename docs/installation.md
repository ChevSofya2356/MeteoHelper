# Установка и настройка

Полное руководство по установке и первичной настройке MeteoHelper.

---

## Системные требования

Перед установкой убедитесь, что устройство соответствует требованиям. Параметры приведены в таблице 1.

**Таблица 1 — Системные требования**

| Параметр | Значение |
|----------|----------|
| Операционная система | Android 13 (API 33) или выше |
| Оперативная память | от 2 ГБ |
| Свободное место | от 50 МБ |
| Сетевое подключение | Wi-Fi или мобильный интернет |
| Поддержка push-уведомлений | обязательно |

## Скачивание APK

Скачать актуальную версию приложения можно из официального репозитория проекта.

📥 **[Скачать MeteoHelper с GitHub](https://github.com/ChevSofya2356/MeteoHelper)**

> Важно: не устанавливайте APK из непроверенных источников. Контрольная сумма SHA-256 публикуется вместе с релизом.

---

## Порядок установки APK

1. Скачайте файл `MeteoHelper.apk` по ссылке выше.
2. Откройте **Настройки → Безопасность → Установка из неизвестных источников** и разрешите установку.
3. Откройте скачанный APK-файл.
4. Подтвердите установку.
5. Дождитесь завершения установки и откройте приложение.

---

## Первичная настройка

1. Заполните профиль (возраст, пол, хронические заболевания, тип метеозависимости).
2. Предоставьте разрешения:
   - **Уведомления** (`POST_NOTIFICATIONS`) — для напоминаний в 07:55;
   - **Точные будильники** (`SCHEDULE_EXACT_ALARM`) — для Android 12+;
   - **Геолокация** (`ACCESS_BACKGROUND_LOCATION`) — для автоопределения региона.
3. Дождитесь загрузки метеоданных на главном экране.

---

## Проверка установки

Для проверки корректной установки выполните команду:

```bash
adb shell pm list packages | grep meteohelper

```
